# VibeMap

Экспериментальная «карта вайба»: пользователь отмечает текущее настроение одним тапом, а карта показывает агрегированные цветовые зоны.

## MVP

- MapLibre GL JS
- определение геопозиции через браузер
- 6 вайбов
- heatmap на карте
- bottom sheet сворачивается при движении карты
- один тап по вайбу сразу добавляет отметку
- пока без бэкенда: данные живут только в текущей сессии

## Запуск

```bash
npm install
npm run dev
```

После запуска открой адрес, который покажет Vite.

> Геолокация браузера обычно работает на localhost или HTTPS.
